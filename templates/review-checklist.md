# 评审检查清单（review-gate 通用）

> 用于所有 `gate: 评审` / `gate: 人工签字` 节点。逐项勾选并记录。

## 通用项
- [ ] 产出物齐全，路径与命名符合 SOP
- [ ] 内容与输入规格/需求一致（可追溯）
- [ ] 无占位符/空章节/未决 TODO
- [ ] 异常与边界情况已覆盖
- [ ] 收敛判据（DoD）全部达标并有证据
- [ ] 遗留问题已列出（风险/影响/责任人）

## 阶段特定项（按需补充）
- [ ] 规格类：指标可量化、可测试；RTM 双向覆盖
- [ ] 架构类：选型有量化依据；无地址冲突
- [ ] RTL 类：编码规范达标；lint/CDC clean；可综合
- [ ] 验证类：覆盖率达标；回归全绿；RCR 关闭
- [ ] 综合/STA 类：DRC clean；WNS/TNS ≥ 0

## 结论
- [ ] 通过 → 签字，置 passed
- [ ] 有条件通过 → 列出修复项，置 iterating，复审
- [ ] 不通过 → 返回执行，置 iterating
