# 参考模型规格模板（Node B7）

> 用途：定义 golden 模型的行为、接口、容差与版本。每个模型一份，存入 `work/soc/docs/model/`。
> 验证期：D2 按本规格接入 scoreboard；D6 按容差策略判 mismatch。

## 1. 模型标识
- 模型名 / 层级（sys / block:<mod>）/ 版本 / golden 冻结日期
- 关联：系统规格条目 / B1 模块 / C1 微架构（如有）

## 2. 输入输出接口
- 输入信号/数据（与 RTL 端口或激励对应）
- 输出信号/数据（scoreboard 比对对象）

## 3. 行为定义
- 功能行为描述
- 时序行为（周期级/事务级/算法级）
- 边界与异常行为（越界、非法输入、复位）

## 4. 容差策略（比对规则）
| 比对项 | 比对方式 | 容差 | 说明 |
|--------|---------|------|------|
| 数据输出 | 逐拍/逐事务精确比对 | 0 | |
| 算法结果 | 浮点误差 | ±ε | ε 取值依据 |
| 时序输出 | 拍数对齐 | 0 / 允许±N拍 | |
| 状态/标志 | 精确比对 | 0 | |

## 5. 性能/效果评估输出（前期用途）
- 该模型支撑的算法效果指标、性能指标（供 B4/A2 对照）

## 6. 验证期接入方式
- 封装形态（SV 行为模型 / DPI-C / cocotb）
- 实例化位置：`verif/block/<mod>/` 或 `verif/sys/`
- 激励同步机制（同激励驱动 DUT 与模型）
