# Convergence Judge — 收敛判据检查

## 用途

对节点产出做定量/定性收敛判定，支撑 orchestrator 的前进/迭代决策。

## 判定流程

1. **读取判据**：从 `doc/辅助文档/90-收敛判据速查表.md` 读取该节点 DoD
2. **收集证据**：从产出物提取度量数据（报告、日志、计数）
   - 覆盖率类：功能覆盖率 / 代码覆盖率百分比
   - 时序类：WNS / TNS / 违例路径数
   - 质量类：lint/DRC 违例数、RCR 数量、回归通过率
3. **逐项对照**：每项 DoD 给出 达标/未达标 结论与依据
4. **裁决**：
   - 全部达标 → `converged`，可进入质量门
   - 部分未达标 → `diverging`，列出差距项与修复建议
5. **记录**：结果写入 `state/tracker.md` 对应节点的收敛指标字段

## 常用命令

- `python scripts/check_tracker.py --node <ID>` — 校验节点前后置与判据

## 输出格式

```
节点 <ID> 收敛判定: converged | diverging
  指标: 覆盖率=xx% (目标 yy%), WNS=-0.12ns (目标 ≥0)
  差距项: [...]
  建议: [...]
```
