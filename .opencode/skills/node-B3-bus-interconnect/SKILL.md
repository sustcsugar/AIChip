# Node B3: 总线与互联选型

> 本 skill 承载节点 B3 的执行工作流。节点完整定义（含人机职责）见 `AIFlow/doc/阶段B-架构与集成规划/B3-总线与互联选型.md`。
> 归属 agent：arch-agent。执行前必须先读 `AIFlow/state/state-tracker.md` 确认节点处于 in_progress 且前置输入完整。

## 1. 目的

选择总线协议与互联拓扑，给出量化依据

## 2. 输入产物（前置条件）

- [ ] 前序节点产物已存在且 passed（见 tracker）
- [ ] 本节点输入清单齐备

## 3. 执行步骤

### Plan
1. 读取输入产物，确认理解目标
2. 若本 skill 的 `assets/templates/` 存在模板，先复制为工作文件
3. **若节点详章指明存在规范/标准文档**（如编码规范、协议标准、模板资产），先读取作为执行约束

### Execute
4. 按输入产物执行本节点工作
5. 产物写入根目录对应路径（`docs/`、`rtl/`、`verif/`、`model/`、`build/`、`ip/` 等，或 `AIFlow/doc/`）；**生成项目文档前先查项目的文档编号登记表（如 `docs/00-文档编号登记.md`，若项目启用）取全局序号（`<前缀>-<NNN>-<名称>.md`），生成后登记**

### Measure
6. 收集度量数据（数量/报告/指标）
7. **输出 friction log**：执行中遇到的卡点/口径冲突/缺失资产/临时变通逐条记录，随节点报告上抛 orchestrator（供 governance-retro 治理回顾；无则显式声明"无"）

### Judge
8. 对照收敛判据逐项检查
9. 不满足 → 定位差距，修正后重测；满足 → 进入质量门

## 4. 工具与命令

- 由节点详章定义（开源工具 / 商用工具脚本 / 校验脚本）
- 校验脚本：`python AIFlow/scripts/check_tracker.py --node B3`

## 5. 收敛判据（DoD）

- 一句话判据：选型有量化依据，满足带宽/时延需求
- **逐项判据与度量口径的唯一事实源**：节点详章 DoD 节（`AIFlow/doc/阶段B-架构与集成规划/B3-总线与互联选型.md`）与速查表（`AIFlow/doc/辅助文档/90-收敛判据速查表.md`），判定时必须逐项对照，不得只看本节摘要

## 6. 质量门与签字

- 质量门类型：评审
- 达标后置 `waiting_review`，等待人工签字后方可 `passed`

## 7. 输出产物

- 产物路径清单见节点详章"输出产物（后置交付）"节（唯一事实源）；产出后登记到项目文档编号登记表（若启用）
