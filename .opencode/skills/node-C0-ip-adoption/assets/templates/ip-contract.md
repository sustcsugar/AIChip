# IP 接口合同模板（Node C0）

> 用途：IP 与 SoC 的接口合同，C0 节点用于合同验证比对。IP 项目维护，SoC 引用。
> 存放：`work/ip/<ip>/doc/interface-contract.md`

## 1. IP 标识
- IP 名称 / 版本 / 维护项目路径

## 2. 总线接口
- 协议（AXI4/AXI4-Lite/APB…）
- 主/从方向、位宽、ID 宽度
- 突发支持 / 对齐要求

## 3. 寄存器映射（Regmap）
- 偏移范围 / 寄存器列表 / 访问属性
- 与 SoC 地址映射的一致性要求（B2）

## 4. 复位与时钟
- 复位极性 / 同步复位要求
- 时钟域数量与频率要求
- 门控与异步复位处理

## 5. 中断
- 中断源数量 / 极性 / 使能控制
- 与 SoC 中断仲裁接口约定

## 6. 配置与状态
- 上电时序 / 配置流程要求
- 状态标志与握手

## 7. 集成约束
- 引脚复用 / 引脚电平
- 电源域要求
- 已知限制（erratum）
