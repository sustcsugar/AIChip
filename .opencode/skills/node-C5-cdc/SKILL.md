# Node C5: CDC检查

> 本 skill 承载节点 C5 的执行工作流。节点完整定义（含人机职责）见 `AIFlow/doc/阶段C-微架构与RTL/C5-CDC检查.md`。
> 归属 agent：rtl-agent。执行前必须先读 `AIFlow/state/state-tracker.md` 确认节点处于 in_progress 且前置输入完整。

## 1. 目的

跨时钟域检查：同步器、亚稳态处理

## 2. 输入产物（前置条件）

- [ ] 前序节点产物已存在且 passed（见 tracker）
- [ ] 本节点输入清单齐备

## 3. 执行步骤

### Plan
1. 读取输入产物，确认理解目标
2. 若本 skill 的 `assets/templates/` 存在模板，先复制为工作文件
3. **若节点详章指明存在规范/标准文档**（如编码规范、协议标准、模板资产），先读取作为执行约束

### Execute
4. 按输入产物执行本节点工作
5. 产物写入根目录对应路径（`docs/`、`rtl/`、`verif/`、`model/`、`build/`、`ip/` 等，或 `AIFlow/doc/`）；**生成项目文档前先查项目的文档编号登记表（如 `docs/00-文档编号登记.md`，若项目启用）取全局序号（`<前缀>-<NNN>-<名称>.md`），生成后登记**

### Measure
6. 收集度量数据（数量/报告/指标）

### Judge
7. 对照收敛判据逐项检查
8. 不满足 → 定位差距，修正后重测；满足 → 进入质量门

## 4. 工具与命令

- 由节点详章定义（开源工具 / 商用工具脚本 / 校验脚本）
- 校验脚本：`python AIFlow/scripts/check_tracker.py --node C5`

## 5. 收敛判据（DoD）

- 一句话判据：无 CDC 违例
- **逐项判据与度量口径的唯一事实源**：节点详章 DoD 节（`AIFlow/doc/阶段C-微架构与RTL/C5-CDC检查.md`）与速查表（`AIFlow/doc/辅助文档/90-收敛判据速查表.md`），判定时必须逐项对照，不得只看本节摘要

## 6. 质量门与签字

- 质量门类型：检查
- 达标后置 `waiting_review`，等待人工签字后方可 `passed`

## 7. 输出产物

- 产物路径清单见节点详章"输出产物（后置交付）"节（唯一事实源）；产出后登记到项目文档编号登记表（若启用）

## 8. 人机职责

| 角色 | 职责 | 干预点 |
|------|------|--------|
| AI agent | 执行主体工作 + 度量 + 判据自检 | 自动执行 |
| 人类 | 质量门签字 / 关键决策 / 异常裁定 | 必须人工确认 |
