# ADR 模板（架构决策记录）

> 用途：`state/state-decisions.md` 决策日志的条目格式标准。每个关键决策登记一条，按 ADR-NNN 递增。
> 格式参考 Michael Nygard《Documenting Architecture Decisions》标准结构 + 本项目溯源字段。

## 模板

```markdown
### ADR-NNN — <决策标题>
- 日期：YYYY-MM-DD
- 状态：已确认 / 已否决 / 已废弃 / 已取代（被 ADR-MMM 取代）
- 背景（Context）：为什么需要这个决策（问题、约束、触发因素）
- 决策（Decision）：决定是什么（含关键选项与选择理由）
- 后果（Consequences）：
  - 正面：…
  - 负面：…
  - 风险/代价：…
- 依据：决策来源（评审/用户指示/数据/文档）
- 落地：落实位置（文件/流程/产物，可含 commit）
```

## 填写指引

| 字段 | 必填 | 说明 |
|------|------|------|
| 标题 | ✅ | 一句话概括决策 |
| 日期 | ✅ | 决策确认日期 |
| 状态 | ✅ | 已确认 / 已否决 / 已废弃 / 已取代 |
| 背景 Context | ✅ | 不写背景的决策无法追溯"为什么" |
| 决策 Decision | ✅ | 明确、可执行 |
| 后果 Consequences | ✅ | 至少各一条正面/负面 |
| 依据 | ✅ | 人类指示 / 评审结论 / 数据 / 文档链接 |
| 落地 | 建议 | 落点文件路径，便于审计 |
