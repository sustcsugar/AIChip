# 节点 F5：时序收敛评审

> 阶段 F STA 时序收敛 | 归属 agent：signoff-agent | 对应 skill：`.opencode/skills/node-f5-timing-signoff/`

## 1. 节点目的与范围

时序收敛关口（**全局强制收敛关口 2**）：汇总 F2/F3 的全部 STA 结果，向人类呈现 WNS/TNS/违例路径证据，完成时序收敛人工签核。签核通过后，设计进入 G 阶段签核与交付。

范围：全 scenario 时序结果汇总、最差路径证据打包、签核结论文档化。不包含功耗（F4，可选）与交付打包（G1）。

## 2. 输入产物（前置条件）

- [ ] 前序节点产物（由 `state/tracker.md` 确认 passed）：F3 违例修复（检查通过）、F1 约束签核、F2 STA 分析、E5 LEC
- [ ] F3 修复后全 scenario STA 汇总 `fixed_sta_summary.csv` 与最差路径报告
- [ ] F1 签核版 SDC（含 changelog）、E3 网表（含可能的修复版）
- [ ] F4 功耗结果（若执行）
- [ ] 全局收敛判据（SOP 总纲）：所有角下 WNS/TNS ≥ 0（或达标）

## 3. 执行步骤

### Plan
- 汇总 F2 口径下全部 scenario 的 WNS/TNS/违例路径数，确认与 F3 修复后数据一致
- 明确产物清单：时序收敛报告、签核证据包、签字记录

### Execute
- 复核关键数据：重新核验全局最差 WNS/TNS（口径与 F2 一致），确认无 scenario 遗漏、无修复后再违反
- 抽取最差违例路径证据：`report_checks -path_delay max -slack_lesser_than 0 -path_type full -max_paths 1` 各 scenario 最差路径；如已收敛则 `report_checks -path_delay max -max_paths 1` 展示最小正 slack 路径作为证据
- 整理证据包：全 scenario 汇总表（WNS/TNS/违例路径数）+ 最差路径详细报告 + SDC 版本 + 网表版本 + LEC 通过记录
- 编制时序收敛签核报告（`timing_signoff.md`）：结论、证据表、口径定义、遗留项（如时钟网络 DRC 已知项）
- 提交人类评审与签字：按 SOP 关口 2 流程，关口前停下等人工签字，未签字不得进入 G 阶段

### Measure
- 收集：全 scenario WNS/TNS、违例路径数（应全部为 0 或满足达标值）、证据包完整性清单

### Judge
- 所有角下 WNS ≥ 0 且 TNS = 0（或满足约定达标值）
- 证据完整、口径统一、无遗留未决违例
- 不满足 → 回 F3 继续修复（必要时回退 C）；满足 → 提交人工签字 → 进入 G 阶段

## 4. 工具与命令

- 工具：PrimeTime 复核；商用工具由人机协同脚本驱动
- 汇总命令：
  - `report_checks -path_delay max -slack_lesser_than 0 -path_type full -max_paths <n>`（确认无 setup 违例）
  - `report_checks -path_delay min -slack_lesser_than 0 -path_type full`（确认无 hold 违例）
  - 收敛展示：`report_checks -path_delay max -max_paths 1`、`report_checks -path_delay min -max_paths 1`（最紧的正 slack 路径）
  - `report_analysis_view` 复核 scenario 集合完整性
  - `report_constraints -all_violators` 复核 DRC/时序约束
- 汇总脚本：`scripts/signoff_aggregate.py` — 汇总全 scenario WNS/TNS/违例数生成签核表；`scripts/check_tracker.py` 复核关口 2 判据
- 证据留档：签核报告、汇总 CSV、最差路径报告、工具日志版本快照

## 6. 收敛判据（DoD）

**WNS/TNS ≥ 0（关口 2）**，判定方法：
- 全部 scenario（模式 × 角）WNS ≥ 0 且 TNS = 0（口径与 F2/F3 一致），违例路径数为 0
- 若与人类约定「达标值」（预留 margin 的目标），以约定为准并注明
- 证据包完整：汇总表 + 最差路径报告 + SDC/网表版本 + LEC 通过记录
- 满足 → 提交人工签字，关闭时序收敛环 Loop 2

## 7. 质量门与签字

- 质量门类型：人工签字（**全局强制收敛关口 2**）
- 呈报内容：全 scenario WNS/TNS 汇总表、最差路径详细报告（slack、路径起点/终点、经过单元）、SDC 与网表版本、遗留项清单
- **关口前必须停下等人工签字；未签字不得进入 G 阶段**
