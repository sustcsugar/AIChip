# C3 编码规范（RTL Coding Standard）

> 版本：v1.0
> 状态：项目规范（唯一真相源）
> 适用范围：SoC 自研模块（`work/soc/rtl/`）与 IP 项目模块（`work/ip/<ip>/rtl/`）的所有可综合 RTL。
> 执行方式：rtl-agent 编码前读取本规范；编码后用 `templates/c3-selfcheck.md` 逐模块自检留档。
> 配套检查：C4 lint 节点（`verilator --lint-only -Wall` 等）做机器复核。

## 1. 语言与可综合子集

- 语言：SystemVerilog（SV-2012 常用语法），**仅可综合子集**。
- 时序逻辑：只用 `always_ff`；组合逻辑：只用 `always_comb`。
- 禁止：
  - `always_latch`（任何遗留 latch 均为违规）
  - 混合边沿触发（同一 `always_ff` 内同时 posedge/negedge）
  - `initial` 进综合（仅 TB 可用）
  - 不可综合构造（`fork/join`、`wait`、动态数组、`$display` 等仅限 TB）
  - 同一进程内阻塞/非阻塞赋值混用
  - `always_ff` 内用阻塞赋值，`always_comb` 内用非阻塞赋值

## 2. 命名规范

| 对象 | 规则 | 示例 |
|------|------|------|
| 模块名 | `<功能名>`，小写下划线，与文件名一致 | `uart_rx` |
| 信号名 | 小写下划线；有意义、含方向/功能语义 | `tx_data_valid` |
| 低有效信号 | 后缀 `_n` | `rst_n` |
| 时钟 | 后缀 `_clk`；时钟使能后缀 `_en` | `apb_clk` |
| 复位 | 统一 `rst_n`（异步复位低有效），按域命名 | `sys_rst_n` |
| 寄存器 | 与 C1 Regmap 表同名，加 `_r` 表示锁存值 | `tx_ctrl_r` |
| 参数/宏 | 大写 + 下划线 | `DATA_WIDTH` |
| 类型（enum/struct） | `typedef` + 大驼峰 | `State_t` |

## 3. 位宽与类型

- 所有信号显式声明位宽，禁止位宽隐式截断/扩展（`$bits()` 显式转换）。
- 位宽不匹配赋值必须显式对齐，或加 `localparam` 统一宽度来源（优先来自 `defines.svh` 公共参数）。
- 无符号/有符号语义明确（算术用 `signed` 需显式声明）；禁止符号性混用未显式转换。

## 4. 同步设计

- 时序逻辑全部时钟沿触发；避免组合环路。
- 状态机：
  - `typedef enum` 定义状态；`always_comb` 次态 + `always_ff` 现态。
  - **显式缺省分支**处理非法状态（回 `IDLE` 或安全态）。
  - 状态编码用独热或二进制并在 C1 说明。
- 防 latch：`always_comb` 内所有分支必须覆盖全部输入路径；`case` 带 `default`；`if` 带完整 `else`。

## 5. 单驱动与多驱动

- 每个信号**单一驱动器**，禁止多进程写同一信号。
- 三态输出仅在顶层 pad 使用，内部禁止 `z` 比较。

## 6. 时钟域隔离（CDC）

- 跨时钟域信号只经同步器（2FF/3FF）或异步 FIFO 交接；禁止跨域组合直连。
- 单 bit 控制/状态：双触发器同步器；多 bit 数据：异步 FIFO 或握手机制（valid/ready）。
- 每个跨域边界在代码注释中标注 `<CDC: 源域→目的域, 机制>`，供 C5 检查追踪。
- 异步复位：统一异步置位/复位 + 同步释放（异步复位同步释放）。

## 7. 复位

- 时序逻辑统一异步复位 `rst_n`；复位值必须与 C1 Regmap 复位值一致。
- 禁止复位仅依赖局部 `if(!rst_n)` 而未定义复位值（可能产生 x 状态）。

## 8. 参数化与文件组织

- 单模块单文件：`<module>.sv`。
- 公共参数/宏集中在 `work/soc/rtl/common/defines.svh`（或 IP 内 `common/defines.svh`），禁止模块内散布魔法数。
- 端口声明顺序：时钟/复位 → 输入 → 输出 → 双向（按 C2 契约顺序）。

## 9. 注释要求

- 每个模块头：功能概述、时钟域、复位策略、关键握手、参考 C1/C2 文档 ID。
- 每个状态机、握手、CDC 边界、Regmap 位域必须注释。
- 注释语言：中文或英文一致（项目默认中文注释）。
- 禁止大段注释掉代码（用版本管理代替）。

## 10. 违规分级

| 级别 | 定义 | 处理 |
|------|------|------|
| Blocker | 不可综合/功能错误/多驱动/latch | 必须修复 |
| Warning | 命名/位宽/规范不符，功能可能受影响 | 必须修复或显式 waiver |
| Info | 风格建议 | 可选 |

## 11. 与相邻节点关系

- 编码输入：C1 微架构规格、C2 接口契约、B2 地址映射。

- 机器复核：C4 lint（分级 + waiver 流程）。
