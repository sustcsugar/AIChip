# 节点 D6：回归与覆盖率收敛

> 阶段 D 验证 | 归属 agent：verify-agent | 对应 skill：`.opencode/skills/node-D6-coverage-closure/`

## 1. 节点目的与范围

运行全量回归，收敛功能与代码覆盖率至目标。本节点是收敛环 Loop 1 的 **Measure + Judge 核心**：汇总 D3–D5 全部用例做全量回归，统计功能覆盖与代码覆盖，未达标则**回到 D3–D5 增补用例**后重跑，形成闭环迭代。

范围：
- 两级全量回归：`verif/block/<mod>` 全量 + `verif/sys` 全量。
- 覆盖类型：代码覆盖（line/branch/toggle/cond/fsm）+ 功能覆盖（coverpoint）+ 断言覆盖。
- mode 切换检查：签核前 sys 级须以 `mode: rtl` 跑全量（`mode: model` 为早期集成）。

## 2. 输入产物（前置条件）

- [ ] D5 断言 passed（断言无失败基线）
- [ ] D1 vplan passed（第 5 节覆盖率目标 = 本节点收敛基准）
- [ ] 全部用例集（D3 定向 + D4 随机多 seed + D5 断言）
- [ ] `work/soc/ip_manifest.json`（mode 配置：model / rtl）

## 3. 执行步骤

### Plan
1. 汇总用例集（定向 + 随机多 seed + 断言触发场景），建立回归矩阵（block / sys × model / rtl）。
2. 确认覆盖率目标值（来自 vplan 第 5 节，未量化则按下节基线补齐）。
3. 确定收集项：line/branch/toggle/cond/fsm + 功能 coverpoint + 断言覆盖。

### Execute
4. 编译带覆盖率收集的仿真镜像（Verilator `--coverage-*` 全开关）。
5. 运行全量回归（block + sys），用例级日志落盘。
6. 收集并**合并**覆盖率：`verilator_coverage -write merged.dat *.dat`（代码）；cocotb-coverage / UVM XML 合并（功能）。
7. 生成覆盖率报告与缺口分析（未覆盖行/分支/功能点清单）。
8. **若未达标 → 回到 D3–D5 增补用例 → 重跑本节点**（收敛环迭代，每轮记录增补与覆盖率提升）。

### Measure
9. 记录度量：回归用例总数、通过率（%）、各覆盖类型百分比、缺口列表、迭代轮次。
10. 运行 `python scripts/check_tracker.py --node D6`。

### Judge
11. 对照收敛判据逐项检查（见第 6 节）。
12. 不满足 → 增补用例迭代；满足 → 进入质量门。

## 4. 工具与命令

- **编译（Verilator 全覆盖率）**：
  - `verilator --binary -j 0 --timing --assert --cc --coverage --coverage-line --coverage-toggle --coverage-branch --coverage-cond --top-module <dut> tb_top.sv`
- **回归运行器**：Makefile target / `scripts/run_regression.sh`；每用例独立 seed、独立日志。
- **覆盖率合并与分析**：
  - `verilator_coverage -write merged.dat <logdir>/*.dat`（合并）
  - `verilator_coverage -annotate <outdir> merged.dat`（生成注解报告）
- **功能覆盖**：
  - cocotb-coverage：`coverage.report_coverage()` / dump JSON，跨 seed 合并。
  - UVM：`covergroup` + `uvm_info` dump（`+UVM_VERBOSITY=UVM_HIGH` 输出 XML/日志）。
- **缺口分析**：解析覆盖率报告列出 `uncovered line/branch/coverpoint`（可写 `scripts/coverage_gap.py`）。
- **RTL 变更重回归**：RCR 修复后对受影响模块 + sys 全量重跑。
- 状态校验：`python scripts/check_tracker.py --node D6`。

## 6. 收敛判据（DoD）

**功能+代码覆盖率达标，回归全绿。**

可操作判定方法（含覆盖率目标值设定方式）：
- **回归**：通过率 = 100%（0 fail / 0 error / 0 crash / 0 超时）。
- **代码覆盖目标**（默认基线，vplan 可提高或按模块调整）：
  - line ≥ 90%；branch ≥ 80%；toggle ≥ 70%；cond/fsm ≥ 80%。
- **功能覆盖**：vplan 第 5 节全部功能 coverpoint ≥ 95%，且每个 vplan TP 至少 hit 一次。
- **断言覆盖**：D5 断言 ≥ 90% 触发。
- **目标值来源**：以 D1 vplan 量化为准；未量化时采用上述默认基线并在本节点落定（更新 vplan）。
- **收敛环规则**：任一覆盖项 < 目标 → 记录缺口 → 回 D3–D5 增补 → 重跑，直至达标。
- sys 级以 `mode: rtl` 全量回归通过。
- `python scripts/check_tracker.py --node D6` 通过。
