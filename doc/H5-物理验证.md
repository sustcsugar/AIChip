# 节点 H5：物理验证

> 阶段 H 物理设计（可选扩展） | 归属 agent：signoff-agent | 对应 skill：`.opencode/skills/node-H5-phys-verify/`

## 1. 节点目的与范围

对最终版图做**签核级物理验证**：DRC（设计规则检查）、LVS（版图与电路一致）、ERC（电学规则检查），确认版图可制造且与 netlist 语义一致，最终达到 **DRC/LVS clean**。这是 tapeout 前的最后一关。

范围：
- DRC：工艺设计规则全量检查（几何/间距/天线/密度/密封环等）。
- LVS：提取版图网表并与综合后 netlist 比对，确保连接一致。
- ERC：电学规则（floating net、pg 短路、ESD 路径等）。
- Antenna / 金属密度 / 可制造性（DFM）检查。
- 签署物理验证报告（签字后版图冻结）。

> 前置说明：H 阶段为可选扩展。仅启用 tapeout 时执行。本节点完成后 H 阶段闭合，物理签核结果回填 G2 收敛报告（如适用）。

## 2. 输入产物（前置条件）

- [ ] H4 Signoff STA 通过（WNS/TNS ≥ 0，`state/tracker.md` 中 H4 = passed）
- [ ] 最终版图 GDS/OASIS（或版图数据库）+ 对应 netlist（逻辑网表，含电源地）
- [ ] PDK 验证文件：DRC rule deck、LVS rule deck（含 extraction 文件）、ERC 规则、天线规则
- [ ] 物理验证工具（Calibre / PVS / 或其他 signoff DRC/LVS 工具）
- [ ] 层映射/连接性定义（层与网名映射、PG 网识别）

## 3. 执行步骤

### Plan
- 确认 H4 已签字、版图与 netlist 版本一一对应（GDS 与签名网表同源）。
- 配置验证规则集（DRC/LVS/ERC/天线/密度），确认工艺版本与 PDK 一致。

### Execute
- 导出最终版图：`streamOut` GDS/OASIS；导出网表（含 PG 网，`write_netlist`）。
- DRC：运行 `drc <rule_deck>`，输出违例报告；按类型（spacing/width/antenna/密度）分类统计。
- LVS：`lvs -hier -alert`（提取版图网表 → 与逻辑网表比对），检查不匹配项（short/open/device 不匹配）。
- ERC：检查 floating net、unconnected pin、PG 连接异常、ESD 相关规则。
- 密度检查：`metalFill`/density rule 满足 fab 最低金属密度要求。
- 修复循环：违例 → 回 P&R 修（ecoRoute/修 DR）→ 重新提取重跑，直至 clean。

### Measure
- 指标：DRC 违例总数（按类）、LVS 不匹配数（short/open/device）、ERC 违例数、天线违例数、金属密度覆盖（%）。
- 记录：每轮修复后违例数量与类型变化。

### Judge
- 对照第 6 节判据：DRC = 0 违例、LVS 完全匹配（无 short/open/device mismatch）、ERC clean、密度达标。
- 不满足 → 修复重跑（可回 H2/H4）；满足 → 进入质量门（人工签字）。

## 4. 工具与命令

- 版图导出（P&R 工具）：`streamOut <chip>.gds -units 1000 -merge <filler/tap 处理>`；网表：`write_netlist -pg`。
- 物理验证（Calibre 等）：
  - DRC：`calibre -drc -hier -turbo <drc_rule>` → `drc_violations.rpt`
  - LVS：`calibre -lvs -hier -turbo <lvs_rule>` → `lvs_reports.txt`（比对结果 + mismatch 分类）
  - 提取：`extract` + `compare`（版图→网表比对）
  - ERC：`calibre -erc` → `erc_violations.rpt`
  - 天线：`calibre -drc`（antenna rules in deck）→ antenna 违例分类
- 汇总脚本：`grep` 解析报告，生成 `phys_verify_summary.rpt`（每类违例计数 + clean 判定）。

## 6. 收敛判据（DoD）

**DoD：DRC/LVS clean。**

可操作判定方法：
- DRC：全规则违例数为 0（含 spacing/width/antenna/密度/密封环等），规则版本与 PDK 匹配。
- LVS：版图提取网表与逻辑网表完全一致——无 short、无 open、无 device 不匹配、无节点不匹配。
- ERC：无电学违规（floating net、unconnected pin、PG 异常）。
- 密度/DFM：金属密度满足 fab 要求（缺失则 metal fill 后复验）。
- 一致性：验证用 GDS 与 H4 STA 版图同源（同一次 streamOut），网表与签名网表一致。
- 可复现：给定 GDS + rule deck 可重复得到同一 clean 结果。
- 判定结论：全部满足 → DRC/LVS clean 成立；否则修复重跑。
