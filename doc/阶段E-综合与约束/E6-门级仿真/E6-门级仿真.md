# 节点 E6：门级仿真

> 阶段 E 综合与约束 | 归属 agent：syn-agent | 对应 skill：`.opencode/skills/node-e6-gate-sim/`

## 1. 节点目的与范围

以门级网表做冒烟仿真，验证综合后网表在功能上与 RTL 行为一致，捕获 LEC 之外的风险（如初始化、时钟门控、异步复位、`x` 传播、库单元行为）。本节点为**可选**：门级仿真冒烟通过可作为额外保障；若资源有限，可仅以 LEC + RTL 回归作为功能基线。

范围：对 E3 网表（可选反标 SDF）运行冒烟用例集，检查输出与参考无 mismatch。不替代 D 阶段全量回归。

## 2. 输入产物（前置条件）

- [ ] 前序节点产物（由 `state/tracker.md` 确认 passed）：E5 形式验证（检查通过）、E3 门级网表、E4 DRC clean
- [ ] E3 门级网表 `top_netlist.v`；可选 `top.sdf`
- [ ] E2 库（仿真模型：.v 门级模型或 .lib 功能抽象，取决于仿真器）
- [ ] D 阶段冒烟用例子集（取 D6 回归中覆盖复位/初始化/主要数据通路的少量用例）
- [ ] 测试平台：RTL 级测试环境（TB）及参考输出

## 3. 执行步骤

### Plan
- 选定冒烟用例（10~20 条覆盖关键路径与边界，不追求全量回归）
- 决定是否反标 SDF（反标 → 含延迟行为，跑慢但更真实；不反标 → 功能冒烟，快）
- 明确产物清单：编译日志、仿真日志、mismatch 统计

### Execute
- 编译门级网表 + 门级库模型 + TB，生成仿真可执行文件
- 配置初始化：复位释放、时钟启动、存储器初始化（网表级需确保不出现未初始化 `x` 依赖）
- SDF 反标（若启用）：`$sdf_annotate("top.sdf", <dut>)` 或仿真器级 `-sdf_file` 选项；检查反标覆盖率的告警（unresolved instance/timing 缺失）
- 运行冒烟用例，比对输出（自检比较器/参考向量差分）
- 分析 mismatch：区分功能性问题、`x` 传播/初始化差异、仿真模型差异（非真实 bug）
- 捕获 X 态：检查 `$error`/mismatch 计数与首次出现位置

### Measure
- 收集：编译通过与否、SDF 反标覆盖率（百分比）、用例通过数、mismatch 数、运行时间

### Judge
- 无 mismatch（0 条），全部冒烟用例通过
- 若 mismatch > 0：分类根因（真实功能 bug / 初始化差异 / 仿真模型问题）；真实 bug 回 C 阶段，模型问题记录为已知项
- 不满足 → 修复或回退；满足 → 进入质量门（检查）

## 4. 工具与命令

- 工具：商用仿真器（VCS / Xcelium / Questa）或开源 Verilator（若库有可综合模型）；由人机协同脚本驱动
- VCS 门级编译示例：
  - `vcs -sverilog +v2k top_netlist.v <lib_model> tb_top.v -sdf top.sdf -o simv`
- Xcelium / Questa 等价：`xrun` / `vsim` + `-sdf_file` 或 `$sdf_annotate`
- Verilator（开源，仅无 SDF 延迟冒烟）：`verilator --binary --timing`（门级 netlist 兼容性取决于库模型）
- SDF 反标：`$sdf_annotate("top.sdf", dut_path)`；`$sdf_version` 一致性检查
- 比对：TB 自检（`assert`/scoreboard）或 `scripts/compare_sim.py` 差分
- 日志度量：`scripts/check_gatesim.py` 解析日志统计 mismatch/error 计数

## 6. 收敛判据（DoD）

**无 mismatch**，判定方法：
- 冒烟用例全部通过，mismatch/error 计数 = 0
- 若启用 SDF：反标覆盖率为 100%（无 unresolved instance），告警已核销
- 若存在已知仿真模型差异项：已文档化且有依据，不掩盖

## 7. 质量门与签字

- 质量门类型：检查（check）
- 检查重点：mismatch = 0、用例覆盖选择合理、SDF 反标完整（如启用）
- 未签字不得放行进入 F 阶段
