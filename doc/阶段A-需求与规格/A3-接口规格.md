# 节点 A3：接口规格

> 阶段 A | 归属 agent：spec-agent | 对应 skill：`.opencode/skills/node-A3-interface-spec/`

## 1. 节点目的与范围

- **目的**：定义系统全部外部与模块间接口规格：引脚、总线、中断、存储映射、时钟/复位、寄存器接口初版，并冻结接口清单。
- **范围**：四类接口（引脚 / 总线 / 中断 / 存储映射）规格化 + 时钟/复位接口 + 寄存器接口初版；冲突与遗漏自动检查；建立机器可读数据源供后续 C0 合同校验复用。
- **不在本节点范围**：总线拓扑与互联选型（B3）、微架构级模块接口契约（C2）。本节点定"SoC 对外长什么样"，模块内部分工留到 C 阶段。
- **输出格式**：`spec-NNN-interface-spec.md` + CSV 数据源（`spec-NNN-pins.csv` / `spec-NNN-memory-map.csv` / `spec-NNN-irq.csv`），CSV 作为单一数据源自动生成 Markdown 表格。

## 3. 执行步骤

### Plan
- 从系统规格导出接口清单，按四类组织（引脚/总线/中断/存储映射），另立时钟/复位与寄存器接口
- 确定接口数据源格式（CSV）与生成关系（CSV → Markdown 表格）

### Execute
- **引脚规格**：信号名、方向（in/out/inout）、位宽、IO 电气属性（类型/驱动/上拉）、复位值、复位源
- **总线接口**：协议（如 AXI/APB）、主从方向、位宽、带宽需求、outstanding/突发能力、ID 宽度
- **中断规格**：中断源、中断号（唯一）、极性/触发方式、可屏蔽性、事件语义（边沿/电平）
- **存储映射**：地址空间划分、每外设基地址与大小、属性（读/写/安全/回读清零）、重叠检查
- **时钟/复位接口**：时钟域与频率、时钟使能、复位极性、复位层次（POR/软复位/域复位）
- **寄存器接口初版**：偏移地址、位域定义、读写属性、复位值（供 C1/C2 细化）

### Measure
- 接口条目数；四类清单是否齐备（引脚/总线/中断/存储映射）
- 冲突扫描：引脚名重复、地址重叠、中断号重复、信号位宽不一致、引用未定义信号
- 遗漏核对：每个 A1 场景 `UC` 涉及的外部交互是否都有对应接口定义

### Judge
- 对照收敛判据：接口清单冻结、无遗漏、无冲突
- 不满足 → 回到 Execute 修正数据源；满足 → 建立冻结基线并进入质量门评审

## 4. 工具与命令

- **数据源工具**：CSV（`pins.csv` / `memory-map.csv` / `irq.csv`），脚本据此生成 Markdown 规格表（避免手写漂移）
- **冲突/遗漏校验脚本**（建议新增 `scripts/check_interface.py`）：
  ```
  python scripts/check_interface.py --pin work/soc/docs/spec/spec-NNN-pins.csv \
      --map work/soc/docs/spec/spec-NNN-memory-map.csv --irq work/soc/docs/spec/spec-NNN-irq.csv
  # 输出：引脚重名 / 地址重叠 / 中断号重复 / 引用未定义信号 / 位宽不一致
  ```
- **复用 IP 背景**：`python scripts/contract_check.py --list` 查看可用 IP 接口能力
- **前置校验**：`python scripts/check_tracker.py --node A3 --deps A1,A2`
- **关系图**：Mermaid 表达总线主从关系与地址映射视图
- **冻结基线**：`git add work/soc/docs/spec/*.csv *.md && git commit -m "interface-spec frozen"` + `git tag`（A3 冻结标记）

## 6. 收敛判据（DoD）

- **接口清单冻结，无遗漏**

判定方法：
- 四类接口（引脚/总线/中断/存储映射）清单齐备，`scripts/check_interface.py` 输出为空（无冲突、无引用未定义）
- 无遗漏：每个 A1 `UC` 场景涉及的外部交互均有对应接口定义（遗漏核对列表为空）
- 唯一性：引脚名唯一、地址区间无重叠、中断号唯一、信号位宽一致
- 冻结基线已建立（git commit + tag，A3 状态 passed）
