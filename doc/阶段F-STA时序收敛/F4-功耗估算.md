# 节点 F4：功耗估算

> 阶段 F STA 时序收敛 | 归属 agent：signoff-agent | 对应 skill：`.opencode/skills/node-f4-power-est/`

## 1. 节点目的与范围

基于门级网表估算功耗（动态 + 静态），与 A2/B4 设定的功耗预算对照，确认满足预算。本节点为**可选**：功耗非本实验强制收敛项，但若预算紧张或 B4 建模值与实现偏差大，应执行。

范围：功耗模型配置、翻转活动率（SAIF/VCD）导入、动态（switching+internal）与静态（leakage）功耗报告、时钟门控效果评估、预算比对。不包含电源网络 IR 分析（物理设计阶段）。

## 2. 输入产物（前置条件）

- [ ] 前序节点产物（由 `state/tracker.md` 确认 passed）：F2 STA 分析（或 F3 修复后版本）、E5 LEC
- [ ] E3 门级网表（与 STA 同版本）与功耗库（.lib 内 power 数据 / power-specific 库）
- [ ] F1 签核 SDC
- [ ] 功耗预算：A2 系统规格 / B4 功耗建模报告中的预算值与场景
- [ ] 翻转活动率来源：D 阶段 VCD/SAIF 文件（代表性用例）或 `set_switching_activity` 预设
- [ ] 时钟门控信息：E3 `clock_gating.rpt`（门控率）

## 3. 执行步骤

### Plan
- 确认预算场景（典型/全速/睡眠模式）与对应活动率来源
- 明确产物清单：功耗报告、预算对照表、降低项建议（如超预算）

### Execute
- 读入网表与功耗库：`read_verilog`/`link_design`（PrimeTime PX 或 `report_power` 流程）
- 施加签核 SDC；设置功耗分析：
  - 导入翻转活动：`read_vcd <file> -strip_path <dut>` 或 `read_saif <file>`；无向量时 `set_switching_activity -type rates|probabilities -activity_factor <x> -static_probability <y>`
  - 设定电源电压：`set_voltage`/电源库属性（多电源域按域设置）
- 时钟门控评估：`report_clock_gating` 统计门控寄存器比例
- 计算与报告：
  - `report_power -hierarchy -levels <n>`（总功耗与层次分解：switching/internal/leakage）
  - `report_switching_activity`（确认活动率导入覆盖率）
  - `report_power -by_hierarchy -sort {power}` 定位高功耗模块
- 与预算比对，计算余量（margin = 预算 − 估算）

### Measure
- 收集：总功耗（动态/静态分项）、层次分解、时钟门控率、活动率覆盖率、与预算偏差

### Judge
- 满足预算（估算 ≤ 预算），或偏差在约定容差内且有说明
- 不满足 → 输出降低建议（增门控、降翻转率、换低功耗单元、约束重综合）并评估是否回 E3/C 阶段；记录预算修订申请（如有）
- 本节点可选：未执行时结论记为「未执行，功耗非本实验强制项」

## 4. 工具与命令

- 工具：PrimeTime PX（PrimeTime Power）、或 DC `report_power`/GENUS `report_power`；商用工具由人机协同脚本驱动
- 分析流程（PrimeTime PX）：
  - `read_verilog top_netlist.v`；`link_design`
  - `read_sdc soc_top.sdc`；`update_timing`
  - `read_vcd <dump.vcd> -strip_path <tb>.<dut>` 或 `read_saif <file.saif> -strip_path <dut>`
  - `report_switching_activity -list_not_annotated`（活动率缺口）
  - `set_power_analysis_options -waveform_format fsdb|vcd|saif`
  - `report_power -hierarchy -levels 3`
  - `report_power -sort_by {total} -by_hierarchy`
  - `report_clock_gating -detail`
- 功耗分项口径：总功耗 = 动态（switching 电容充放电 + internal 短路/宏功耗）+ 静态（leakage，随角与温度变化）
- 脚本：`scripts/run_power.tcl` + `scripts/parse_power.py`（解析 → 预算对照表）

## 6. 收敛判据（DoD）

**满足预算**，判定方法：
- 估算总功耗 ≤ 预算（含分项明细），时钟门控率与活动率覆盖率已记录
- 若超预算：已给出降低建议并裁定处置方向（回 E/C 优化 或 走预算修订流程）
- 若未执行：结论明确标注「可选节点未执行」，不影响 F5 时序签核

## 7. 质量门与签字

- 质量门类型：检查（check）
- 检查重点：功耗分项完整、活动率来源可信、预算比对结论明确
- 未签字不得进入 F5
