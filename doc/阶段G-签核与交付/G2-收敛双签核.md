# 节点 G2：收敛双签核

> 阶段 G 签核与交付 | 归属 agent：signoff-agent | 对应 skill：`.opencode/skills/node-G2-dual-signoff/`

## 1. 节点目的与范围

本节点是**全局收敛的最终确认点**：把功能收敛环（Loop 1，止于 D7 关口1）与时序收敛环（Loop 2，止于 F5 关口2）的证据合拢，判定芯片"功能 + 时序"双收敛成立，并输出正式收敛报告（按 `templates/convergence-report.md`）。

范围：
- 收集 D7（功能收敛）与 F5（时序收敛）的签核证据。
- 补充核对约束/DRC/LEC 等旁证。
- 汇总遗留问题与风险。
- 输出收敛报告，交人工签字完成双签核。
- 本节点**不新做**验证/STA，只做证据汇总、交叉检查与最终判定。

## 2. 输入产物（前置条件）

- [ ] G1 交付包已完成并签字（`state/state-tracker.md` 中 G1 = passed）
- [ ] **D7 功能收敛证据**：验证签核结论（无未决 RCR）、功能覆盖率报告、代码覆盖率报告、回归通过率（100%）、`templates/review-checklist.md` 勾选记录
- [ ] **F5 时序收敛证据**：全模式全角 STA 签核报告（WNS/TNS ≥ 0）、F1 约束签核评审、F2 违例清单、F3 修复记录
- [ ] 旁证：SDC 签核结论、综合 DRC 报告（E4）、LEC 等价性报告（E5）、功耗报告（F4，如做）
- [ ] 交付物清单（G1 输出 `DELIVERY_MANIFEST.json`）
- [ ] 遗留问题/风险清单（来自各阶段评审纪要、decisions.md）

## 3. 执行步骤

### Plan
- 确认 G1 已签字、D7 与 F5 状态均为 passed。
- 按 `templates/convergence-report.md` 的 6 节结构准备报告骨架。
- 明确证据路径（文件 + 行号/报告名/日期），保证可追溯。

### Execute
- **功能侧**：从 D7 报告抽取覆盖率、回归通过率、RCR 数量；核对 D7 签字人/日期。
- **时序侧**：从 F5 报告抽取各模式/角 WNS/TNS 与违例路径；核对 F5 签字人/日期。
- **旁证核对**：SDC 结论、综合 DRC、LEC 结果写入报告第 4 节。
- 交叉一致性检查：netlist 版本 = E5 LEC 版本 = F5 STA 版本 = G1 交付包版本；约束版本 = F1 评审版本。
- 汇总遗留问题与风险（含未验证项、已知限制、后续建议）到报告第 5 节。
- 生成收敛报告草稿，提交质量门人工签字。

### Measure
- 汇总关键数字：功能覆盖率、代码覆盖率、回归通过率、未决 RCR 数、各角 WNS/TNS、违例路径数。
- 记录证据来源（报告路径 + 生成日期）数量与一致性核对结果（全部一致 / 存在不一致）。

### Judge
- 逐项比对：功能证据满足 D7 关口判据、时序证据满足 F5 关口判据。
- 双收敛判定：两关口**均**成立且证据一致，才算收敛确认。
- 任一不满足或证据不一致 → 打回对应阶段（回 D 或 F）修正后重取证据，不得在本节点"特批放行"。

## 4. 工具与命令

- 报告生成：按 `templates/convergence-report.md` 模板填写，产出 `work/soc/deliverables/<soc_version>/CONVERGENCE_REPORT.md`。
- 证据抽取：`grep`/脚本从 D7、F5 报告中提取指标；或由 `scripts/check_tracker.py` 校验 tracker 状态。
- 版本一致性：`git diff --stat` 对比交付包与冻结 tag；比对 `DELIVERY_MANIFEST.json` 中版本号。
- 判定辅助：`convergence-judge` skill 的判据检查清单。
- 签字留痕：报告中签字区（签字人 + 日期）由人工填写，AI 不得代签。

## 6. 收敛判据（DoD）

**DoD：功能 + 时序双收敛确认。**

可操作判定方法：
- 功能侧：D7 签核成立（无未决 RCR）+ 回归通过率 100% + 功能/代码覆盖率达标（≥ 目标值，见 D6）。
- 时序侧：F5 签核成立（全模式全角 WNS/TNS ≥ 0，或按 F3 达标注记），无未签核角。
- 证据一致性：报告内所有指标与原始报告数值一致；版本链条（RTL→netlist→LEC→STA→交付包）逐级可追溯。
- 遗留问题：第 5 节中无阻塞性未决项；非阻塞项有明确处置建议。
- 结论栏：报告第 6 节"功能收敛确认 / 时序收敛确认"均勾选，签字人、日期齐全。
- 判定结论：全部满足 → 双收敛确认成立；否则打回重取证。

## 7. 质量门与签字

- 质量门类型：人工签字（收敛报告双签核：功能收敛 + 时序收敛，签字人签名并注明日期）。
- 未签字不得进入 G3 基线归档；本节点为全局收敛最终确认，签字即宣布收敛闭环。
