# 产物目录约定

> 本文件定义芯片设计项目产物的目录结构与命名规范，供节点 skill 在执行时落地具体路径。
> **详章（AIFlow/doc/阶段*）中不得引用本文件的具体路径**，详章只描述产物内容与用途。

## SoC 项目产物（`docs/`）

| 目录 | 内容 | 命名规范 |
|------|------|---------|
| `docs/spec/` | 系统规格、接口规格、收敛矩阵 | `spec-NNN-<名称>.md` + `.csv` |
| `docs/arch/` | 架构产物（系统架构、地址映射、总线选型等） | `arch-NNN-<名称>.md` + 配套 |
| `docs/regmap/` | 寄存器描述（SystemRDL，ADR-026） | `<module>.rdl`（每外设一个） |
| `docs/microarch/` | 微架构规格（每模块一份） | `<module>.md`（8 节结构） |
| `docs/interfaces/` | 模块接口契约 | `<module>.md` + `interface-matrix.md` |
| `docs/vplan/` | 验证计划 | `vplan-NNN-<名称>.md` |
| `docs/reviews/` | 评审纪要与 checklist | `<节点ID>-<module>.md` |
| `docs/reports/` | 自检报告、覆盖率报告 | `<节点ID>-<类型>.md` |
| `docs/00-文档编号登记.md` | 全局编号登记（001 起，NNN 三位递增） | 唯一文件 |
| `docs/index.md` | 全局导航 | 唯一文件 |

## SoC RTL/验证/综合产物

| 目录 | 内容 |
|------|------|
| `rtl/` | RTL 源码（含 `rtl/inc/` 生成常量包） |
| `rtl/inc/` | 从 `docs/B2-addr-map.yaml` 自动生成的地址常量（`build_addr_map.py` 产物，不可手改） |
| `verif/` | 验证环境（`common/`、`block/<mod>/`、`sys/`） |
| `model/` | 参考模型（`block/<mod>/`、`sys/`） |
| `build/` | 综合构建产物 |
| `soc/sw/include/` | 从地址映射自动生成的 C 头文件（`build_addr_map.py` 产物，不可手改） |

## IP 项目产物（`ip/<ip>/`）

| 目录 | 内容 |
|------|------|
| `ip/<ip>/AIFlow/doc/` | IP 项目层 SOP + 详章（与 SoC 层平行结构） |
| `ip/<ip>/AIFlow/doc/regmap.yaml` | IP 寄存器描述（若 IP 有独立 regmap；集成时由 C0 合并到 `docs/regmap/`） |

## 编号规则

- 文档编号：`NNN`（三位，从 001 起，项目全局递增），登记于 `docs/00-文档编号登记.md`
- 文档命名：`<编号>-<名称>.md`（如 `008-system-arch.md`）
- 评审纪要：`<节点ID>-<模块>.md`（如 `c1-uart.md`）
