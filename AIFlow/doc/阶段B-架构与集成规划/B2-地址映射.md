# 节点 B2：地址映射

> 阶段 B | 归属 agent：arch-agent | 对应 skill：`.opencode/skills/node-b2-address-map/`

## 1. 节点目的与范围

定义完整地址映射（Memory map），含寄存器空间：确定 SoC 内所有主设备可访问的从设备地址窗口、寄存器空间（regmap）以及地址译码表。为总线互联（B3）提供译码依据，为后续 RTL（译码逻辑 / axi_addr_pkg）与软件（base address 头文件）提供唯一事实源。

范围：
- 存储空间：DDR / SRAM / ROM / 预留区
- 外设空间：mipi/usb/ddr 控制器、axi_uart、GPIO、定时器、中断控制器等从设备窗口
- 寄存器空间：每个模块的寄存器偏移 / 位域 / 属性（RW/RO/W1C/自清）/ 复位值
- 地址译码表：主设备索引 → 从设备窗口

不涉及：总线协议与拓扑（B3）、模块内部微架构寄存器细节实现（C1）。

## 2. 输入产物（前置条件）

- [ ] B1 系统架构：模块划分、数据流（`AIFlow/state/state-tracker.md` 确认 passed）
- [ ] A3 接口规格：总线 / 存储映射需求（passed）
- [ ] A5 规格 v1.0：容量 / 性能要求（passed）

- [ ] 外部输入：SoC 地址空间宽度、对齐约束（AXI 页面大小 / 突发边界）

前置校验命令：`python AIFlow/scripts/check_tracker.py --node B2`

## 3. 执行步骤

### Plan
- 汇总所有需要地址空间的从设备，统计各自所需窗口大小与对齐约束
- 确定地址布局策略：按地址宽度分区（存储 / 外设 / 私有 / 调试），预留扩展区

### Execute
- 分配地址窗口：每个从设备的基址、大小、对齐（如 4KB 对齐），预留 hole 与扩展空间
- 寄存器空间：逐模块建立寄存器表（偏移 / 名 / 位域 / 属性 / 复位值），复用 IP 直接并入其已发布 regmap
- 生成地址译码表：主设备可访问性矩阵 + 译码优先级
- 生成代码产物：SystemVerilog 地址包（`axi_addr_pkg.sv`）、C 头文件（`soc_addr.h`）

### Measure
- 冲突检测：全部窗口两两求交，结果 = 无重叠
- 对齐检查：所有窗口满足协议 / 总线对齐要求
- 译码复杂度：窗口数、译码级数、是否溢出地址空间

### Judge
- 对照 DoD（无地址冲突、无重叠）逐项检查，以脚本结果为准
- 每个从设备恰好一个窗口；主设备可访问性矩阵完整
- 不满足 → 修正重测；满足 → 进入质量门（检查）

## 4. 工具与命令

- 地址映射唯一事实源：按节点 skill 规定的目录与命名
- 生成与检查脚本：`AIFlow/scripts/build_addr_map.py`（YAML → 冲突 / 重叠 / 对齐检查 + 生成 RTL 包与头文件）
  - 运行：`python AIFlow/scripts/build_addr_map.py --map <地址映射YAML文件> --out rtl/inc/`
- 冲突检查报告：按节点 skill 规定的目录与命名（列出所有两两窗口重叠 / 越界 / 未对齐，失败返回非 0）
- 复用 IP regmap 合并：读取 `ip/<ip>/AIFlow/doc/regmap.yaml` 并入主映射
- 产物编译冒烟：`verilator --lint-only -f rtl/inc/axi_addr_pkg.sv`（验证生成的 RTL 包语法）

## 6. 收敛判据（DoD）

DoD：无地址冲突、无重叠。

可操作判定方法：
- `build_addr_map.py` 输出无 ERROR：全部窗口互不重叠、不越界（上限 ≤ 空间上限）、满足对齐
- 每个从设备恰好一个主窗口，无歧义映射
- 全部复用 IP 寄存器空间已并入且无冲突
- 生成产物可编译：`axi_addr_pkg.sv` 通过 Verilator lint（`verilator --lint-only`）无 error
