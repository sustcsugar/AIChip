# 节点 E2：库环境设置

> 阶段 E 综合与约束 | 归属 agent：syn-agent | 对应 skill：`.opencode/skills/node-e2-lib-env/`

## 1. 节点目的与范围

配置逻辑综合所需的工艺库、计算环境（PVT 角）与脚本环境：完成 target/link 库读入、search path 与变量设置，验证库数据完整读入无误，并固化为可复用的环境脚本，供 E3 综合与 F2 STA 共用。

范围：综合库（.db/.lib）、符号库、设计库（DC synthetic library）、search_path、operating conditions、单位一致性检查、库缺省 DRC 值检查。不包含布线后寄生提取（物理设计阶段）。

## 2. 输入产物（前置条件）

- [ ] 前序节点产物（由 `AIFlow/state/state-tracker.md` 确认 passed）：E1 约束开发（评审通过）、C7 RTL 冻结
- [ ] 工艺库文件：target library（.db 或 .lib）、link library、symbol library、synthetic library（DW，DC 用）
- [ ] 工艺角信息：各 PVT 角（SS/FF/TT 等）与 RC 角对应的 operating condition 名称
- [ ] 库数据手册：标准单元名、驱动能力范围、时钟单元类型、默认 DRC 建议值
- [ ] 外部输入：EDA 工具版本与授权（license）确认、工作目录权限

## 3. 执行步骤

### Plan
- 核对库文件清单与工艺角映射，明确 target（逻辑映射）与 link（例化解析）库集合
- 明确产物清单：`env_setup.tcl`、库读入日志、库完整性检查报告

### Execute
- 编写 `env_setup.tcl`：设置 `search_path`、`target_library`、`link_library`、`symbol_library`、`synthetic_library`（DC）或 `init_lib_search_path` + `read_libs`（GENUS）
- 执行库读入，捕获 `list_libs`/`report_lib` 确认每个库被成功解析（检查读入的单元数、无 warning 级缺失）
- 设置 operating conditions：`set_operating_conditions`（DC，可按分析视图/角分别设置）或 `set_db operating_condition`（GENUS）
- 单位检查：`report_units` 确认 time/capacitance/resistance/voltage 单位与约束假设一致
- DRC 缺省值核查：读取库内默认 `max_transition`/`max_capacitance`/`max_fanout`，与 E1 的 `set_max_*` 目标核对（避免约束与库能力矛盾）
- 记录工具版本、license 信息，保证可复现

### Measure
- 收集：库数量、单元总数、每个库读入状态、warning 计数、单位/角信息

### Judge
- 每个声明的库均读入成功，无缺失单元；单位一致；operating conditions 与工艺角映射正确
- 不满足 → 修正 search_path/库清单重读；满足 → 进入质量门（检查）

## 4. 工具与命令

- 工具：DC（Design Compiler）、GENUS；驱动方式为人机协同脚本
- DC 环境命令：
  - `set_app_var search_path <lib_dirs>`
  - `set_app_var target_library {*.db}`、`set_app_var link_library {*.db dw_foundation.sldb}`、`set_app_var symbol_library {*.sdb}`
  - `set_app_var synthetic_library dw_foundation.sldb`
  - `set_operating_conditions <cond>`（可配合 `-library`）
- GENUS 环境命令：
  - `set_db init_lib_search_path <lib_dirs>`
  - `read_libs <lib_list>` 或 `set_db library <lib_list>`
  - `set_db operating_condition <cond>`
- 校验命令：
  - `list_libs`、`report_lib <lib>`（DC）；`report_libs`（GENUS）
  - `report_units`（单位一致性）
  - `report_operating_conditions` / `get_lib_cells *` 计数核对
  - `check_library`（库数据完整性，可选）
- 一致性核对：`AIFlow/scripts/check_lib_env.py`（自定义脚本，比对声明库清单与实际读入清单）

## 6. 收敛判据（DoD）

**库读入无误**，判定方法：
- 声明的 target/link/symbol 库全部读入成功，`list_libs`/`report_lib` 中单元数 > 0 且无缺失单元错误
- `report_units` 中 time/capacitance/resistance 单位与库手册一致
- operating conditions 覆盖后续 STA 所需的全部 PVT/RC 角，映射正确
- 读入日志仅含已记录的已知警告（如可忽略的 unread 单元），无阻塞性错误
- 环境脚本可一键复现（幂等）

## 7. 质量门与签字

- 质量门类型：检查（check）
- 检查重点：库清单完整性、读入状态、单位与角一致性、可复现性
- 未签字不得进入 E3 综合
