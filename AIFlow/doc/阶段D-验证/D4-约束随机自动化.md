# 节点 D4：约束随机自动化

> 阶段 D 验证 | 归属 agent：verify-agent | 对应 skill：`.opencode/skills/node-D4-constrained-random/`

## 1. 节点目的与范围

开发约束随机用例，增加测试自动度。通过约束随机激励自动探索地址、数据、配置的组合空间，覆盖定向测试遗漏的边界与交互场景，并将多 seed 随机用例纳入回归集合。

范围：
- vplan 中 `测试类型=随机` 的 TP（两级环境）。
- 随机 sequence / 生成器开发（cocotb 随机激励生成器或 UVM constraint 类）。
- 多 seed 批量运行 + 结果聚合分类。
- 目标：以随机组合大规模提升验证自动度，为 D6 覆盖率收敛提供增量。

## 2. 输入产物（前置条件）

- [ ] D3 定向用例 passed（功能基线已建立）
- [ ] D1 vplan passed（提取"随机"类型 TP 与合法/非法约束空间）
- [ ] C1 微架构规格 passed（合法地址、配置寄存器范围、协议规则）
- [ ] D2 TB 环境可用（随机用例直接跑在既有环境中）

## 3. 执行步骤

### Plan
1. 提取 vplan 随机 TP，定义约束空间：合法地址/数据/配置组合 + 边界 + 非法注入 + 竞争窗口。
2. 设计 seed 管理策略（默认 seed 池 10–100，固定 seed 可复现）。
3. 确定结果分类规则：预期断言失败（非法激励触发保护）/ 未预期失败（= 崩溃或 RTL bug）。

### Execute
4. 编码随机激励：cocotb 随机生成器（`random.randint`、`BinaryValue` 随机化）或 UVM `rand` / `randcase` / `constraint` 类。
5. 构造约束：合法随机（覆盖主功能空间）、边界随机（边界/越界地址、满/空、最大深度）、错误注入（非法操作、握手中断）。
6. 批量运行：多 seed × 多用例；日志落盘。
7. 结果聚合：扫描日志，按"通过 / 预期断言失败 / 未预期失败 / 超时挂死"分类。
8. 稳定的随机用例纳入回归集合（D6 回归基础）。

### Measure
9. 记录度量：seed 数、运行总时、通过率、预期/未预期失败数、随机用例对 TP 的 hit 数。
10. 运行 `python AIFlow/scripts/check_tracker.py --node D4`。

### Judge
11. 对照收敛判据逐项检查（见第 6 节）。
12. 不满足 → 定位根因（环境 bug / 约束错误 / RTL bug）→ 修复重测；满足 → 进入质量门。

## 4. 工具与命令

- **cocotb 随机**：
  - `import random`；`random.randint`、`random.choice`；`cocotb.binary.BinaryValue` 随机位填充。
  - 时序随机化：`cocotb.triggers` 随机延时（`await Timer(random.randint(...))`）。
  - 功能覆盖点埋点：cocotb-coverage（`coverage.CoverageBin`）供 D6 合并。
- **UVM 约束随机**：
  - 字段声明 `rand bit [ADDR_W-1:0] addr;` + `constraint c { addr inside {...}; addr != ...; }`。
  - 随机化调用：`assert(item.randomize() with {...});` 或 `uvm_sequence::start_item` 机制。
- **多 seed 批量运行**：
  - `for s in $(seq 1 100); do SIM=verilator make TESTCASE=test_rand SEED=$s; done`
  - 结果聚合脚本：`AIFlow/scripts/agg_regression.py <logdir>`（可新建），统计 pass/fail/crash/timeout。
- **调试**：`WAVES=1 make` 生成波形，gtkwave 查看未预期失败现场。
- 状态校验：`python AIFlow/scripts/check_tracker.py --node D4`。

## 6. 收敛判据（DoD）

**无未预期崩溃。**

可操作判定方法：
- 批量 seed 运行全部正常结束：无进程崩溃、无超时挂死（超时 = 计入失败）。
- 所有失败均可归因：`预期断言失败`（非法激励触发保护机制，属正常）或已登记 RCR（RTL bug）。
- 无未解释的非确定性：固定 seed 重跑结果一致（复现性校验）。
- 随机用例覆盖的 TP 均有 hit 记录（随机对功能覆盖有增量贡献）。
- `python AIFlow/scripts/check_tracker.py --node D4` 通过。
