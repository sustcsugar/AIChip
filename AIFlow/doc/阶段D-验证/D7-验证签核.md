# 节点 D7：验证签核

> 阶段 D 验证 | 归属 agent：verify-agent | 对应 skill：`.opencode/skills/node-D7-verification-signoff/`

## 1. 节点目的与范围

**功能收敛关口（关口1）**：整理 RCR 清单，验证签核。汇总 D1–D6 全部验证证据，审查未决 RCR，向人类呈现覆盖率与回归证据，经人工签字后功能收敛，方可进入阶段 E（综合）。

范围：
- 收集 D1–D6 全部证据产物（vplan / 覆盖率报告 / 回归日志 / RCR）。
- RCR 清单总审（open / closed / 豁免裁定）。
- 产出验证签核报告 + 功能收敛证据表（`.opencode/skills/_shared/templates/convergence-report.md`）。
- 本节点是**全局两个强制收敛关口之一**（关口1），未签字不得进入下一阶段。

## 2. 输入产物（前置条件）

- [ ] D6 回归与覆盖率收敛 passed（`AIFlow/state/state-tracker.md` 确认）
- [ ] D1 vplan passed（第 7 节签核标准 = 本节点判定依据）
- [ ] 全部覆盖率报告、回归日志（D6 产物）
- [ ] RCR 清单（D3–D6 累积的 open/closed 记录）
- [ ] `ip_manifest.json`（签核时 IP 均以 `mode: rtl` 参与全量回归）

## 3. 执行步骤

### Plan
1. 收集 D1–D6 全部证据产物清单，确认路径与完整性。
2. 汇总 RCR 清单（含严重度、状态、责任人）。
3. 准备签核报告结构（复用 `.opencode/skills/_shared/templates/convergence-report.md` 功能收敛证据表）。

### Execute
4. 复核 D6 回归与覆盖率终值（必要时以 `mode: rtl` 复跑一次全量作为签核依据）。
5. 逐条审查 RCR：影响范围、严重度、是否可豁免（豁免需人工裁定并记录）。
6. 填充 `.opencode/skills/_shared/templates/convergence-report.md`：代码/功能覆盖率、回归通过率、未决 RCR。
7. 生成验证签核报告，向人类呈现：覆盖率 + 回归 + RCR 证据三件套。

### Measure
8. 记录度量：未决 RCR 数、closed/豁免 RCR 数、覆盖率/回归终值。
9. 运行 `python AIFlow/scripts/check_tracker.py --node D7`。

### Judge
10. 对照收敛判据逐项检查（见第 6 节）。
11. 不满足 → 列出修复项，回 D 阶段对应节点（D3–D6）修复后重审；满足 → 提交人工签字。

## 4. 工具与命令

- **证据汇总**：扫描 `verif/reports/` 与 `docs/`，生成证据清单（可写 `AIFlow/scripts/collect_signoff_evidence.py`）。
- **报告生成**：填充 `.opencode/skills/_shared/templates/convergence-report.md` 功能收敛证据表（第 2 节：代码覆盖率 / 功能覆盖率 / 回归通过率 100% / 未决 RCR = 0）。
- **RCR 条目格式**（RCR = 验证缺陷记录）：
  - `RCR-<序号> | 标题 | 严重度(阻塞/高/中/低) | 来源节点(D3–D6) | 涉及模块/用例 | 影响 | 状态(open/in_fix/closed/豁免) | 证据链接`
  - 存放：`AIFlow/state/rcr/`（每 RCR 一文件）或 RCR 汇总表 `AIFlow/state/RCR-清单.md`。
- **签核复核**：`verilator_coverage -annotate` 复核覆盖率；回归日志复核 `0 fail`。
- **评审**：`.opencode/skills/_shared/templates/review-checklist.md` 验证类逐项勾选。
- 状态校验：`python AIFlow/scripts/check_tracker.py --node D7`。

## 6. 收敛判据（DoD）

**无未决 RCR（关口1）。**

可操作判定方法：
- **RCR**：未决 RCR 数 = 0；所有 RCR 状态为 `closed` 或经人工裁定 `豁免` 并记录豁免理由。
- **回归**：D6 全绿复跑确认（`mode: rtl` 下通过率 100%）。
- **覆盖率**：line/branch/toggle/cond/fsm + 功能覆盖 ≥ D1 vplan 目标（D6 终值）。
- **证据**：覆盖率报告、回归日志、RCR 清单路径可查且与报告数字一致。
- **签字**：人工在签核报告上签字 = 越过关口1 的唯一凭证；未签字不得进入阶段 E。
- `python AIFlow/scripts/check_tracker.py --node D7` 通过。

## 7. 质量门与签字

- 本关口为全局两个强制收敛关口之一（关口1 功能收敛；关口2 在 F5）。
- 关口前必须停下等人工签字；未签字不得进入下一阶段。
