# 节点 D5：断言与形式化

> 阶段 D 验证 | 归属 agent：verify-agent | 对应 skill：`.opencode/skills/node-D5-assertion-formal/`

## 1. 节点目的与范围

添加断言，可选形式化验证关键属性。断言作为持续在线检查器内嵌 TB，逐周期/逐事件捕获协议、握手、时序违规；对关键属性（互斥、无死锁、复位行为、FIFO 溢出、指针不越界）可选做形式化验证。

范围：
- 两级环境断言：模块接口断言（block 级）+ 系统协议断言（sys 级 AXI 握手/仲裁）。
- 断言与测试类型为"断言"的 TP 对齐（vplan 追溯）。
- 形式化（可选）：仅限关键属性，须评估可证明性与资源（约束完备才跑）。

## 2. 输入产物（前置条件）

- [ ] D4 约束随机 passed（随机激励可自动触发断言路径）
- [ ] D1 vplan passed（提取"断言"类型 TP 与关键属性清单）
- [ ] C1 微架构规格 passed（协议规则、握手时序、状态机不变量）
- [ ] D2 TB 环境可用（断言嵌入既有环境）

## 3. 执行步骤

### Plan
1. 从规格提取协议规则与不变量 → 断言清单（规则号 → 断言）。
2. 选择形式化目标属性：关键、可约束、复杂度可控（排除大循环/长事务）。
3. 确定断言类型：接口断言（block/sys）与关键内部点断言。

### Execute
4. 编码断言：
   - SVA：`assert property (@(posedge clk) disable iff (!rst_n) <expr>);`，Verilator 用 `--assert` 支持。
   - cocotb：`assert <cond>` 结合 `await RisingEdge(clk)` 时序检查。
5. 在模块接口与关键内部点布点，开启断言覆盖（assertion coverage）收集。
6. 全量用例（D3+D4）运行一遍，验证断言无误报、无漏报。
7. （可选）形式化：`sby -f props.sby`（SymbiYosys）或商用工具（JasperGold，人机协同脚本）证明关键属性；产出 proven / 反例。
8. 反例 → 分析：断言约束缺失（修复约束）还是 RTL bug（登记 RCR）。

### Measure
9. 记录度量：断言总数、各断言触发次数、失败数；formal 属性数、proven/反例数。
10. 运行 `python AIFlow/scripts/check_tracker.py --node D5`。

### Judge
11. 对照收敛判据逐项检查（见第 6 节）。
12. 不满足 → 修正断言（误报）或修复 RTL（真 bug）→ 重测；满足 → 进入质量门。

## 4. 工具与命令

- **SVA（Verilator）**：编译加 `--assert`，启动断言使能：
  - `verilator --binary --assert -j 0 --timing --trace --top-module <dut> tb_top.sv`
  - 断言失败 → Verilator 打印 `%Error: Assertion failed`，exit 非 0。
- **SVA（UVM/iverilog）**：`assert property` 内嵌 RTL/TB；`vvp sim.out` 运行时失败即报。
- **cocotb 断言**：`assert` + `cocotb.triggers`；失败抛异常，cocotb 标记用例 fail。
- **断言覆盖（assertion coverage）**：Verilator `--coverage-line` 覆盖断言表达式分支；cocotb 侧用 `coverage.CoverageBin` 记录断言命中。
- **形式化（可选）**：
  - SymbiYosys：`sby -f props.sby`（文件内指定 `yosys` 综合 + `prove` 引擎，如 boolector/SuperProve）。
  - yosys 综合 + BTOR2 引擎；或商用 JasperGold（人机协同脚本）。
  - 形式化前提：约束（assume）完备，否则产生假反例。
- 状态校验：`python AIFlow/scripts/check_tracker.py --node D5`。

## 6. 收敛判据（DoD）

**断言无失败。**

可操作判定方法：
- 全量用例（D3+D4）运行断言失败数 = 0（0 fatal / 0 error，Verilator 无 `Assertion failed`）。
- 断言覆盖收集开启且命中非空（断言不是空转，有实际触发记录）。
- 形式化（若执行）：关键属性均 proven；若有反例，已闭环为 RCR 或已修正约束并重证。
- 断言与 vplan 中"断言"类型 TP 一一映射，无遗漏。
- `python AIFlow/scripts/check_tracker.py --node D5` 通过。
