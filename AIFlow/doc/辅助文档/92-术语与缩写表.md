# 92 — 术语与缩写表

> 用途：集中登记本实验使用的全部缩写/术语。**新增缩写必须先在此登记再使用**（纪律来源：用户 2026-08-20 "新缩写必须先定义再使用"，RT 事件教训）。
> 维护者：orchestrator（唯一写入，与 state-* 纪律一致）。校验：`python AIFlow/scripts/workflow_audit.py` W17（关键缩写已登记、无未登记即使用的项目定义缩写）。

## 一、编号体系（项目定义，语义见 ADR-008）

| 缩写 | 全称 | 定义 / 用途 |
|------|------|------------|
| REQ | Requirement | 需求条目（PRD 根条目，A1 产物） |
| SC | Scenario | 使用场景（验证侧主线，A1 产物） |
| UC | Use Case | 用例（SC 下的具体用例，A1 产物） |
| FS | Functional Specification | 功能规格（REQ 的规格化细化，**不新增需求**，A2 产物） |
| M | Metric | 量化指标（M 表为唯一事实源，A2 产物） |
| FP | Functional Point | 功能点（按功能域从 UC 聚合，A2 产物） |
| CP | Check Point | 检查点（验证侧条目，如有） |
| BLOCK | Block | 物理模块编号 `BLOCK-NN`（结构维度，A2 产物） |
| OI | Open Issue | 全流程需求/规格歧义澄清编号 `OI-<节点ID>-<全局序号>` |

## 二、治理与流程

| 缩写 | 全称 | 定义 / 用途 |
|------|------|------------|
| ADR | Architecture Decision Record | 关键决策记录（`AIFlow/state/state-decisions.md`，Nygard 标准 + 项目溯源字段） |
| RMP | Roadmap | 优化方向统一待办编号 `RMP-NNN`（**原 RT，2026-08-20 改名**；`AIFlow/state/state-roadmap.md`） |
| RCR | Review Change Request | 评审/变更请求（D7 未决 RCR=0 为收敛判据） |
| DoD | Definition of Done | 节点收敛判据（详章 §6，速查表 90） |
| SOP | Standard Operating Procedure | 标准作业流程总纲（`AIFlow/doc/SOP.md`） |
| RTM | Requirements Traceability Matrix | 需求可追溯矩阵（A4 节点产物） |
| PRD | Product Requirements Document | 产品需求文档（`docs/spec/spec-001-PRD.md`） |
| Fsys | System Clock Frequency | 系统运行时钟频率（BLOCK-11 CLKRST 由外部 `clk_i` 生成，默认 50MHz） |

## 三、技术缩写

| 缩写 | 全称 | 说明 |
|------|------|------|
| AXI4 | Advanced eXtensible Interface 4 | 统一总线协议（ADR-009：AXI4 全量） |
| SPI / QSPI | Serial Peripheral Interface / Quad SPI | 串行外设总线（BLOCK-05；QSPI 为 x4 高速方向，见 RMP-002） |
| SCLK | Serial Clock | SPI 串行时钟 |
| PIO | Programmed I/O | 软件编程 I/O（CPU 驱动寄存器逐字节搬数据） |
| MMIO | Memory-Mapped I/O | 内存映射 I/O（外设区 0x4000_0000，RISC-V load/store 访问） |
| XIP | Execute In Place | 片上执行（RMP-001 候选方案） |
| RIB | RISC-V Interconnect Bus | tinyRISCV 处理器内部总线（RIB↔AXI 桥自研） |
| UART | Universal Asynchronous Receiver/Transmitter | 通用异步收发（外设，AF1 复用） |
| IIC | Inter-Integrated Circuit | 两线串行总线（外设，AF1 复用） |
| PWM | Pulse Width Modulation | 脉冲宽度调制（外设，AF1 复用） |
| GPIO | General-Purpose Input/Output | 通用输入输出（AF0/16 路） |
| JTAG | Joint Test Action Group | 调试/测试接口 |
| SRAM | Static Random-Access Memory | 静态随机存储器（AXI_SRAM 运行数据） |
| CDC | Clock Domain Crossing | 跨时钟域（C5 检查节点） |
| LEC | Logic Equivalence Checking | 逻辑等价性检查（E5 形式验证） |
| STA | Static Timing Analysis | 静态时序分析（F 阶段） |
| WNS / TNS | Worst Negative Slack / Total Negative Slack | 时序收敛指标（WNS/TNS ≥ 0） |
| SDC | Synopsys Design Constraints | 时序约束文件（E1/F1） |
| DRC | Design Rule Check | 设计规则检查 |
| CTS | Clock Tree Synthesis | 时钟树综合（H3） |
| RTL | Register Transfer Level | 寄存器传输级（C 阶段产物） |
| SoC | System on Chip | 芯片集成层（根目录项目层） |
| IP | Intellectual Property | 复用模块（`ip/` 项目层，manifest 锁定） |
| MCU | Microcontroller Unit | 微控制器（产品定位） |

## 纪律

1. **新增缩写先登记后使用**：任何 agent 在文档/产物中引入新缩写前，先在本表登记（orchestrator 落账）
2. **行业通用缩写**（如 LED、ID、CS、IRQ）可直接使用，但建议在首次出现处给全称
3. **改名留痕**：缩写改名（如 RT→RMP）须在本表与 ADR 中留痕，避免历史文档误解
4. 校验：W17 检查本表存在且核心项目定义缩写（编号体系 + 治理类）已登记
