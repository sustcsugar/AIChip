## 一、编号体系（项目定义，语义见 ADR-008）

| 缩写 | 全称 | 定义 / 用途 |
|------|------|------------|
| REQ | Requirement | 需求条目（PRD 根条目，A1 产物） |
| SC | Scenario | 使用场景（验证侧主线，A1 产物） |
| UC | Use Case | 用例（SC 下的具体用例，A1 产物） |
| FS | Functional Specification | 功能规格（REQ 的规格化细化，**不新增需求**，A2 产物） |
| M | Metric | 量化指标（M 表为唯一事实源，A2 产物） |
| FP | Functional Point | 功能点（按功能域从 UC 聚合，A2 产物） |
| CP | Check Point | 检查点（验证侧条目，如有） |
| BLOCK | Block | 物理模块编号 `BLOCK-NN`（结构维度，A2 产物） |
| OI | Open Issue | 全流程需求/规格歧义澄清编号 `OI-<节点ID>-<全局序号>` |

## 二、治理与流程

| 缩写 | 全称 | 定义 / 用途 |
|------|------|------------|
| ADR | Architecture Decision Record | 关键决策记录（`AIFlow/state/state-decisions.md`，Nygard 标准 + 项目溯源字段） |
| RMP | Roadmap | 优化方向统一待办编号 `RMP-NNN`（**原 RT，2026-08-20 改名**；`AIFlow/state/state-roadmap.md`） |
| RCR | Review Change Request | 评审/变更请求（D7 未决 RCR=0 为收敛判据） |
| DoD | Definition of Done | 节点收敛判据（详章 §6，速查表 90） |
| SOP | Standard Operating Procedure | 标准作业流程总纲（`AIFlow/doc/SOP.md`） |
| RTM | Requirements Traceability Matrix | 需求可追溯矩阵（A4 节点产物） |
| PRD | Product Requirements Document | 产品需求文档（`docs/spec/spec-001-PRD.md`） |
| Fsys | System Clock Frequency | 系统运行时钟频率（BLOCK-11 CLKRST 由外部 `clk_i` 生成，默认 50MHz） |

## 纪律

1. **新增缩写先登记后使用**：任何 agent 在文档/产物中引入新缩写前，先在本表登记（orchestrator 落账）
2. **行业通用缩写**（如 LED、ID、CS、IRQ）可直接使用，但建议在首次出现处给全称
3. **改名留痕**：缩写改名（如 RT→RMP）须在本表与 ADR 中留痕，避免历史文档误解
4. 校验：W17 检查本表存在且核心项目定义缩写（编号体系 + 治理类）已登记
