# B2 寄存器空间总表（B2-regmap.md）

> 节点 B2 产物 | 归属：arch-agent | 日期：2026-08-21
> 寄存器**初版已由 spec-v1.0 冻结**（spec-005 §6.1~6.8，8 组，含偏移/读写属性/复位值）。本表为 B2 架构级汇编视图：**不重定义、不修改冻结内容**，仅建立"寄存器窗口 ↔ 地址映射 ↔ 译码路径"的对应关系；位域级定义归 C1/C2（spec-005 §9.2 已明确）。

## 1. 寄存器窗口 ↔ 地址映射对应表

| 窗口 | 模块 | 基址 | 大小 | 译码路径（β 结构，ADR-025） | 寄存器定义（冻结源） | 错误响应建议 |
|------|------|------|------|------------------------------|----------------------|--------------|
| MEM-05 | BLOCK-03 UART | 0x4000_0000 | 4KB | 核→RIB→桥→AXI_IB→AXI4→Lite 转换器→Lite 从 | spec-005 §6.1 | 窗口内未实现偏移 SLVERR |
| MEM-06 | BLOCK-05 SPI | 0x4000_1000 | 4KB | 同上 | spec-005 §6.2 | 同上 |
| MEM-07 | BLOCK-06 IIC | 0x4000_2000 | 4KB | 同上 | spec-005 §6.3 | 同上 |
| MEM-08 | BLOCK-07 PWM | 0x4000_3000 | 4KB | 同上 | spec-005 §6.4 | 同上 |

## 2. 非寄存器从设备

| 窗口 | 模块 | 说明 |
|------|------|------|
| MEM-01 | BLOCK-12 Boot ROM | 存储窗口（RO 取指/读），无 regmap |
| MEM-03 | BLOCK-14 AXI_SRAM | 存储窗口（R/W，AXI4 全量保留突发），无 regmap |
| MEM-14 | BLOCK-13 SPI Flash | 外部器件，PIO 访问，无地址映射 |

## 3. 复用 IP regmap 并入状态

按 B2 详章要求应读取 `ip/<ip>/AIFlow/doc/regmap.yaml` 并入主映射。当前 `ip/{axi_uart,ddr,mipi,usb}/` 目录为空（IP 项目层尚未发布，B6 集成规划 / C0 IP 接入时才引入）——**无可并入内容，不阻塞 B2**。B6/C0 引入 IP 后须复核：其 regmap 落入分配窗口（外设保留区 MEM-13 有 0x0FFF_8000 ≈ 255.5MB 扩展空间，且 4KB 粒度窗口在 0x4000_8000 起可线性扩展），并入时重跑 `build_addr_map.py` 冲突检查。
