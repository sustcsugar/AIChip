### 编号体系总览（全称与主脉络）

**缩写全称速查**：

| 编号 | 全称 | 维度 | 数量 | 出自 |
|------|------|------|------|------|
| REQ | Requirement（需求） | 要什么 | 20 | spec-001 |
| SC | Scenario（使用场景） | 在什么情境下用 | 12 | spec-002 |
| UC | Use Case（用例） | 具体怎么操作 | 32 | spec-002 |
| FS | Functional Spec（功能规格） | 系统做什么 | 20 | 本文档 §2 |
| M | Metric（性能指标） | 做到多好 | 20 | 本文档 §3 |
| FP | Functional Point（功能验收点） | 怎么算完成 | 12 | 本文档 §6 |
| CP | Convergence Point（收敛验收点） | 时序/功耗收敛 | 6 | 本文档 §6 |
| BLOCK | 物理模块 | 拆成什么 | 14 | 本文档 §2.1 |
| OI | Open Issue（开放问题） | 需求/规格歧义澄清 | 5（已关闭） | spec-003 |

**主脉络（自上而下）**：

```
                 REQ（要什么）
                 ├─ 设计侧 → FS（做什么）→ 挂接 M（做到多好）
                 └─ 验证侧 → SC → UC → FP（怎么算完成）
                 结构层：BLOCK（物理模块）→ B 阶段细化为架构
```

即：**REQ 为根**，分设计侧（REQ→FS→M）与验证侧（REQ→SC→UC→FP）两条主线；BLOCK 为物理结构层承接架构；OI 贯穿全程记录歧义裁决。

### 编号体系声明（ADR-008）

- **FS 与 REQ 分工**：FS-001~020 是 REQ-001~020 的**规格化细化**（将需求陈述展开为可测试的系统行为），**不新增需求**；若需新增功能，必须先改 PRD 增补 REQ，再在本文档补充对应 FS。FS↔REQ 1:1 对应属刻意设计（REQ=用户视角"要什么"，FS=规格视角"做什么、怎么测"），不是重复。
- **M 表为指标唯一事实源**：本文档 §3 性能指标表是全部量化指标的**唯一事实源**；REQ（spec-001）、详章、后续文档中出现的数字均为**引用**，不得作为独立指标修改入口。指标调整只改 M 表并同步引用处。
- **BLOCK 为物理模块编号**：BLOCK-01~14 标识物理模块（含复用 IP 与自研模块），全文档以 BLOCK-NN 引用；FS 描述行为（逻辑维度）、BLOCK 描述物理构成（结构维度），二者映射见 §2.2 的"对应模块"列，多为多对多。

## 4. 约束

### 4.1 工艺

- **ADR-002（OI-A1-004）**：目标工艺/库**暂不限定**，功能收敛以仿真为主（Verilator + cocotb / UVM）。
- **ADR-004 降级口径**（工艺库确定前的收敛标准）：
  1. 功能收敛（D7）不受影响，正常执行；
  2. E 阶段以开源综合（yosys）验证可综合性与 lint/DRC clean，替代商用 DC 流程；
  3. F 阶段以综合后结构检查 + 延迟估算代替 Signoff STA；
  4. 一旦工艺库就绪（或用户指定），补跑完整 E/F（DC/GENUS + Primetime）作为正式时序收敛证据；G2 双签核需标注时序受限。
- 综合参考目标（E 阶段选一）：Artix-7 FPGA 映射 或 开放 PDK 参考标准单元库（B/E 阶段裁定）。

| 项 | 规格 |
|----|------|
| 时钟域 | 单系统时钟域（同步设计），Fsys = 50 MHz（10–50 MHz 可配） |
| 外设时钟 | UART 波特率、SPI SCLK、IIC SCL、PWM 计数时钟均由 Fsys 分频产生，不引入独立时钟域 |
| JTAG TCK | 异步输入，跨时钟域经同步器处理（C5 CDC 检查项） |
| SPI Flash 时钟 | 由 SPI master SCLK 驱动（外部器件时钟），内部无独立域 |
| 频率指标 | 见 §3 M-002/M-003 |

### 4.3 复位

- 全局**异步复位、同步释放**（async assert / sync deassert）。
- 复位源：上电复位（POR）+ 外部复位输入。
- 复位释放后系统进入已知启动状态并稳定运行（REQ-010；UC-BOOT-003）。

### 4.4 电源

- 单电源域设计（电压档位与 IO 电平 A3/B 阶段细化）。
- 低功耗：空闲模式时钟门控（REQ-014）；唤醒源：外部中断 / GPIO 事件 / UART 事件。
- 功耗预算见 §3 M-016/M-017/M-018。

### 4.5 兼容性与标准

| 类别 | 标准要求 |
|------|---------|
| RISC-V ISA | RV32IM（tinyRISCV 核；ISA 规范版本与核 commit 待 C0 pin 定后确认） |
| 软件工具链 | riscv-gnu-toolchain（RV32IM 目标），编译/链接/加载（REQ-017） |
| 总线协议 | RIB（tinyRISCV 私有总线，契约待 C0 验证）；AXI：AMBA AXI4（RIB↔AXI 桥 AXI 侧，A3 裁定统一 AXI4；突发/outstanding 细节 B3 细化） |
| UART | 异步串行 8N1（芯片侧逻辑电平，RS-232 电平转换由外部完成） |
| SPI | Motorola SPI（SCLK/CS/MOSI/MISO），CPOL/CPHA 四模式可配 |

## 5. 可测试性要求

### 5.1 调试接口

- **JTAG**（REQ-004）：IEEE 1149.1 TAP，支持 openocd 内存/寄存器读/写；IDCODE 可读用于连接诊断；连接失败报错可定位（无响应/IDCODE 异常）且不引起目标挂死。
- 无标准 Debug Module 对调试方案的影响**待 C0 评估**（影响 JTAG 访问机制设计，A2 不假设方案）。

### 5.2 自测试 / BIST

- **固件级自检**（软件自检，SBIST）：bootloader/启动自检——AXI_SRAM 读写回环、SPI Flash 可读性检查、UART 回环、外设寄存器写后读回校验。
- **固件更新校验**（REQ-003）：CRC 校验失败拒绝写入、保留旧固件、断电可恢复（不 brick）。
- **硬件 BIST**：本 MCU 规模（逻辑 ≤ 50k 门）不引入独立硬件 BIST 引擎，以软件自检 + 验证环境承担；可综合性与 DFT 基础要求（复位/可观测）由 E3 验证。
- **DFT 基础**：全同步可复位设计（可扫描结构前提，E 阶段 yosys 验证 DRC clean）。

### 5.3 可观测性

- 验证环境可观测内部状态（REQ-016 接受准则）：内部总线/寄存器观测端口。
- 仿真全信号 dump（VCD/FST）；断言（D5）；scoreboard 自动比对（D2，参考模型 golden，mismatch=0 纳入 D6/D7 判据）。
- JTAG 提供芯片级观测路径（内存/寄存器读）。

## 6. 验收标准

### 6.1 功能验收点（承接 D1 验证计划，覆盖 A1 全部 12 SC / 32 UC）

> **组织维度说明**：FP 按**功能域**从 UC 聚合（一域一验收点，共 12 个）；SC 按**使用情境**组织（也是 12 个）。两者数量巧合相同、主题相近，但维度不同——SC 回答"在什么情境下用"，FP 回答"这组用例怎么算完成"。FP↔SC 映射经 UC 间接建立（见下表"覆盖用例"列）。

| 验收点 | 内容 | 覆盖用例 | 判据 |
|--------|------|---------|------|
| FP-01 | 启动与加载 | UC-BOOT-001~004 | 固件自 SPI Flash 加载执行，无非法指令/挂死 |
| FP-02 | UART 通信 | UC-UART-001~003 | 双向收发无丢失；波特率不匹配可恢复 |
| FP-03 | 固件更新 | UC-UART-004~007 | 下载→校验→写 Flash→跳转；失败保留旧固件、断电可恢复 |
| FP-04 | JTAG 调试 | UC-JTAG-001~003 | openocd 内存/寄存器读写一致；失败可诊断 |
| FP-05 | SPI | UC-SPI-001~003 | 命令写入/数据读取正确；CPOL/CPHA 可恢复 |
| FP-06 | IIC | UC-IIC-001~003 | 寄存器读写一致；NACK 检测；多字节正确 |
| FP-07 | PWM | UC-PWM-001~002 | 波形与配置一致；0%/100% 边界无毛刺 |
| FP-08 | 中断 | UC-INT-001~005 | 三类中断源进入 ISR；屏蔽/清除/优先级有效；风暴不挂死 |
| FP-09 | 低功耗（Should） | UC-PWR-001 | 空闲功耗显著低于运行态；事件唤醒恢复 |
| FP-10 | AXI 访问（RIB↔AXI 桥） | UC-BUS-001 | 桥访问 AXI_SRAM/外设数据一致 |
| FP-11 | GPIO | UC-GPIO-001~002 | 输出可控/输入可读；引脚复用；GPIO 事件触发中断 |
| FP-12 | 验收演示 | UC-DEMO-001 | LED 点灯 + UART 日志 + SPI/IIC/PWM 联动，可重复复现 |

- 功能收敛总判据（D 阶段）：D6 功能+代码覆盖率达标、回归全绿、scoreboard mismatch = 0；D7 无未决 RCR（关口 1，人工签字）。

### 6.2 收敛验收点（对应 F 阶段时序，含 ADR-004 降级口径）

| 验收点 | 内容 | 阶段 | 判据 |
|--------|------|------|------|
| CP-01 | 综合 DRC | E3 | yosys 综合 DRC clean（降级口径）；工艺库就绪后 DC/GENUS 综合 DRC clean |
| CP-02 | 综合后时序 DRC | E4 | max_transition/capacitance/fanout clean |
| CP-03 | 形式验证（LEC） | E5 | RTL ↔ netlist 等价 |
| CP-04 | 时序分析 | F2 | 工艺库就绪后全角 STA：WNS/TNS ≥ 0 @50 MHz（正式口径）；当前降级：结构检查 + 延迟估算 ≥ 50 MHz |
| CP-05 | 时序收敛评审 | F5 | **关口 2：时序收敛签字**（降级口径下标注"待补跑正式 STA"） |
| CP-06 | 功耗估算 | F4 | 估算结果 ≤ M-016/M-017 预算 |
